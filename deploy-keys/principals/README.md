# Principal transition templates

The deploy file accepts only deploy. Each privileged login accepts admin, its box tag,
and its legacy login during transition. Matches are OR, never AND. A box-only cert
must omit admin. Use --retire-legacy / -RetireLegacy only in approved S5.
No template for vibes-asus: its trust is unknown. These files are desired configuration,
not evidence of an applied host state.
