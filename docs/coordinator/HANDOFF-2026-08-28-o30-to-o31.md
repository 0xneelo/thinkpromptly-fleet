   loop variant silently no-opped four pastes.
2. **`/goal` is codex-only syntax.** Claude-breed lanes get PLAIN text — a `/goal` prefix
   is an unknown slash command there and may eat the message.
3. **A box `git fetch` without credentials hangs FOREVER** (credential prompt in a
   non-tty) — this masqueraded as a dead link twice. Always
   `GH_TOKEN=$(broker) GIT_TERMINAL_PROMPT=0 timeout 180 git fetch`, in a shipped script.

   `wsl sh`. Inside the script, normal quoting works. Codex needs its ABSOLUTE path

   the first paste (a too-early paste vanishes silently; footers lag ~10s — never
