# DECK-108 layer 1 (2f8f1e1) — review findings for Bernward, 2026-09-11 ~13:5x local (seat 20, Sonnet reviewer)

Ranked. Fix R1 and R2 in layer 2; R3 is covered by the signer module you are building; R4 is a one-liner.

- **R1 (critical) — fail-closed is missing.** `server.js:3111` only configures auth when `FLEET_DECK_SECRET_FILE` is set, and `up.sh:39` never sets it (no provisioning step exists), so `auth.configured` is false on every real launch and `unblock.js:266` (`if (auth.configured && !operatorId) return 401`) never fires: every PUT answers / close / reopen / send is Origin-gated only, every answer gets `operator_id=null`, `sig=null`, and `fleetdeck-verify-answer` exits 1 for legitimate answers. Your accepted switch (password hash in `~/.fleetdeck/operator.json`, no deck secret) removes that file, but the rule must change too: **when sign-in is not configured, answer writes/close/reopen/send return 503 (not configured), never Origin-only.** The screen shows "sign-in not set up" and the verify CLI reports `unconfigured`. Add a test that boots the deck with no operator.json and asserts a write is refused.
- **R2 (medium) — global lockout = local denial of service.** `operator-auth.js:141` keeps one global `strikes`/`lockedUntil`; any same-user process can POST 5 wrong passwords every 60 s and keep the operator locked out forever. Replace the lockout with a rate limit (e.g. 5 attempts per 60 s window, then `429` with Retry-After) that never extends itself on further attempts during the window, and never blocks a correct password beyond that window. A same-user attacker can kill the deck anyway; do not build more than that.
- **R3 (medium) — signing hard-wired.** `operator-auth.js:62-95,128-146`: `mac()/signAnswer()/answerSigValid()` hardcode HMAC-SHA256 keyed by `secret.hmacKey`, and `loadDeckSecret()` requires a 64-hex `hmacKey`. Covered by your layer-2 signer module (op-agent default, file signer for tests): make `sign(canonicalString) → {sig, signer_id}` and `verify(canonicalString, sig) → bool` the only two calls the routes and the CLI use; delete the HMAC path rather than keeping it as a third backend.
- **R4 (low) — `GET /api/operator/session` has no Origin check** (`operator-auth.js:111`), unlike signin/signout. Add it for consistency.
