# The red thread

The operator's directions, verbatim, newest at the bottom. Append-only.

Written only by `goalkeeper.py thread add`. Never hand-edited — the value of this file is that
every line is the operator's own words, and an edit is indistinguishable from a paraphrase.

A direction is a **general heading** with a date and a horizon (`day` or `week`), not a task, not
a card, not a lane. "today monday 7th september i want the lowcapsxyz consensus page re-designed"
is a direction. "XYZ-1858" is not.
